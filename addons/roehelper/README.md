# RoE Helper (lite)

Records of Eminence helper for Ashita v4.

The lite build has no themes, skins, custom fonts or images: one plain ImGui look with the normal window title bar, and a highlighted button for "on". All features are the same as the full version (1.11.4). The window scale bar and the Look button are not in the lite build.

## Install
Copy the `roehelper` folder into `Ashita\addons\` and run `/addon load roehelper`.
